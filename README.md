This homebrew tap automates the installation and updating of the nightly version of Neovim.

# Usage
1. Unlink or uninstall existing neovim `brew unlink neovim`/`brew uninstall neovim`
2. Tap this repository `brew tap yuanmich2/neovim-nightly`
3. Trust this repository `brew trust --cask yuanmich2/neovim-nightly/neovim-nightly`
4. Install neovim nightly `brew install neovim-nightly`
5. Run neovim using `nvim` in the command line
